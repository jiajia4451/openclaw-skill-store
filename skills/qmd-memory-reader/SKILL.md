# QMD Memory Reader — 完整记忆读取服务

**类型**: 系统服务 (System Service)  
**频率**: 每4小时自动执行 (+手动触发)  
**功能**: 完整QMD记忆扫描 + 生成详细报告

---

## 🎯 核心功能

| 功能 | 描述 | 输出 |
|------|------|------|
| **记忆统计** | 统计所有记忆文件数量和类型 | 表格展示 |
| **索引检查** | 验证QMD索引健康状态 | 状态摘要 |
| **核心文件解析** | 读取SOUL/USER/MEMORY/今日记忆 | 结构化摘要 |
| **项目状态** | 扫描projects/目录 | 项目清单 |
| **智能搜索** | 执行示例QMD搜索 | 搜索结果 |
| **健康检查** | 检测超大文件/重复文件/空文件 | 警告列表 |

---

## ⏰ 执行方式

### 自动执行 (推荐)
```
定时: 每4小时 (00:00, 04:00, 08:00, 12:00, 16:00, 20:00)
方式: Cron 定时任务
报告: 自动保存到 memory/qmd-reports/
```

### 手动执行
```bash
cd ~/.openclaw/workspace/skills/qmd-memory-reader/scripts
bash full-memory-reader.sh
```

---

## 📁 输出结构

```
memory/
```

## 🔧 安装


1. 设置脚本权限

3. 初始化服务状态文件

## 📈 使用场景

1. **启动后恢复** — 获取完整上下文
2. **每日检查** — 确保记忆系统健康
3. **问题排查** — 检查索引状态和文件完整性
4. **性能优化** — 识别超大文件和重复文件

---

## ⚠️ 注意事项

- 报告生成可能需要 10-30 秒 (取决于记忆文件数量)
- 首次执行会自动检测并提示QMD状态
- 建议每3-7天查看一次最新报告
- 超大文件警告阈值: >500KB
