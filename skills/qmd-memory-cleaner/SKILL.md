# QMD Memory Cleaner — 记忆清理服务

**类型**: 系统服务 (System Service)  
**频率**: 手动触发 (+ 可配置 cron)  
**功能**: 分析记忆库健康状况，生成清理建议

⚠️ **重要**: 本服务**不会自动删除任何文件**！它只生成清理建议报告，删除操作需要人工审核后手动执行。

---

## 🎯 核心功能

| 清理类别 | 检测内容 | 风险等级 |
|----------|----------|----------|
| **旧文件** | 超过30天未访问的记忆文件 | 🟡 建议归档 |
| **重复文件** | *副本*、*.bak*、*~* 等备份 | 🔴 建议删除 |
| **超大文件** | 超过500KB的单个记忆文件 | 🟡 建议拆分 |
| **空文件** | 内容过少( <100字节 )的文件 | 🔴 建议删除 |
| **死循环风险** | "自动执行"、"无需确认"等危险触发词 | 🔴 需要审查 |
| **过时技能** | 超过14天未修改的技能目录 | 🟡 检查状态 |

---

## 🚀 使用方式

### 手动执行 (推荐)
```bash
cd ~/.openclaw/workspace/skills/qmd-memory-cleaner/scripts
bash memory-cleaner.sh
```

### 定期执行 (可选)
```bash

0 3 */3 * * cd /path/to/scripts && bash memory-cleaner.sh
```

## 🛡️ 安全准则

### ⚠️ 本服务承诺

1. **只读分析** — 仅读取和扫描文件，不执行任何修改
2. **建议为主** — 只生成建议报告，不自动删除
3. **人工审核** — 所有清理操作必须人工确认后执行
4. **备份优先** — 建议的清理命令使用 `mv` 而非 `rm`

### 📋 删除前检查清单

使用本服务建议后，操作前请确认：

- [ ] 已查看清理报告中的文件内容 (`cat 文件路径`)
- [ ] 已创建备份 (`cp -r memory/ memory.backup-$(date +%Y%m%d)/`)
- [ ] 确认文件已过时，不再需要
- [ ] 优先使用 `mv` 归档，而非 `rm` 删除

## 📈 检测规则详解

### 旧文件检测
```bash
-atime +30  # 30天未访问
```

### 重复模式
```
*.backup*
*.copy*
*副本*
*.bak
*~
*#*
```

### 超大文件
```
-size +500k  # >500KB
```

### 空文件
```
-size -100c  # <100字节
```

### 死循环风险词
```
"自动执行" "无需确认" "立即执行"
"系统服务" "自动触发" "无条件执行"
```
