# QMD 记忆系统整合方案

> 三重记忆：每日文件 + 长期记忆 + 语义索引

---

## 🎯 核心问题

当前痛点：
- ❌ 写了记忆文件，但找的时候翻半天
- ❌ 没有系统性整理到MEMORY.md
- ❌ 忘记搜索过往会话记录

解决方案：
- ✅ QMD语义搜索所有记忆
- ✅ 自动索引每日记忆文件
- ✅ 定期整理到长期记忆

---

## 🏗️ 三层记忆架构

### 第1层：原始记忆（Raw Memory）
```
memory/
├── 2026-02-17.md           ← 每日对话记录
├── 2026-02-16.md
├── moltbook-*.md          ← 项目/专题记忆
└── session-*.md           ← 会话总结
```
**特点**：原始、详细、未经整理
**索引**：QMD自动索引

### 第2层：语义索引（Semantic Index）
```
QMD Collection: openclaw-memory
├── 所有.md文件自动嵌入向量
├── BM25全文搜索
└── 向量语义搜索
```
**特点**：快速检索、理解语义
**更新**：文件变更后自动重新embed

### 第3层：长期记忆（Long-term Memory）
```
MEMORY.md
├── 关键决策记录
├── 项目里程碑
└── 学习总结
```
**特点**：精选、结构化的长期知识
**维护**：每周从每日记忆中提取

## 🔄 工作流程

### 对话开始时（自动执行）
```
用户提问
    ↓
1. QMD搜索关键词（从用户问题提取）
   → 返回最相关的5个记忆片段
2. 读取这些片段作为上下文
3. 同时搜索过往会话（sessions_history）
4. 结合回答
```

### 工作结束时（自动执行）
```
重大工作完成
    ↓
1. 写入 memory/YYYY-MM-DD.md
2. QMD embed 更新索引
3. 检查是否需要更新MEMORY.md（关键决策？）
4. 如果是关键决策 → 自动追加到MEMORY.md
```

### 每周整理（Heartbeat自动执行）
```
每周日执行
    ↓
1. QMD搜索过去7天的所有内容
2. 提取关键决策、里程碑、教训
3. 更新MEMORY.md长期记忆
4. 清理过时的临时记忆
```
