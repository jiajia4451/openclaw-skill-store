# Recording Rules — 自动记录触发条件与格式规范

## 实时记录触发条件 (Auto-Record Triggers)

当以下情况发生时，立即调用 `record.sh` 记录到 `memory/YYYY-MM-DD.md`：

### 🔴 必须立即记录

| 触发条件 | 示例 | 优先级 |
|---------|------|--------|
| **代码变更** | 修改了核心文件、发布版本 | 紧急 |
| **重要决策** | "我们决定..."、"放弃..."、"转向..." | 紧急 |
| **用户说记住** | "记住这个"、"记下来" | 高 |
| **里程碑完成** | "v2.0完成"、"功能上线" | 高 |
| **错误/教训** | 踩坑记录、解决方案 | 高 |
| **项目状态变更** | 暂停、启动、放弃 | 中 |
| **技术发现** | 找到bug原因、关键洞察 | 中 |
| **约定/规则** | 新工作流程、行为准则 | 中 |

### 🟡 选择性记录

| 触发条件 | 判断标准 |
|---------|----------|
| 创意想法 | 有具体实现价值时记录 |
| 资源发现 | 对项目有直接帮助时记录 |
| 学习笔记 | 首次接触的重要概念 |
| 待办事项 | 需要跨会话追踪时 |

## 记录格式模板

### 决策记录 (Decision)

```markdown
## 🎯 [时间] — 决策记录

**决策内容**: [简述]

**背景**: [为什么做这个决定]

**选择**: [方案A vs 方案B，为什么选这个]

**影响**: [对现有项目/计划的影响]

**执行者**: 大饼 ₿
```

### 代码变更 (Code Change)

```markdown
## 📝 [时间] — 代码变更

**文件**: `path/to/file.ext`

**变更**: [简述做了什么]

**原因**: [为什么需要改]

**回滚命令** (如果风险高):
```bash
git checkout [tag] -- file
```
```

### 里程碑 (Milestone)

```markdown
## 🚀 [时间] — 里程碑: [名称]

**完成内容**: [具体完成了什么]

**版本**: vX.Y.Z

**Git标签**: `[tag-name]`

**当前状态**:
- 功能: [已完成/待完成]
- 测试: [已通过/待测试]

**下一步**: [接下来做什么]
```

### 错误/教训 (Lesson)

```markdown
## ⚠️ [时间] — 教训记录

**问题**: [发生了什么]

**原因**: [为什么会发生]

**解决**: [怎么解决的]

**防止再犯**: [以后怎么避免]
```

### 用户备忘 (Memo)

```markdown
## 💡 [时间] — 用户备忘: [主题]

**内容**: [用户要求记住的内容]

**触发**: 用户说"记住这个"

**有效期**: [永久/直到某日期]
```

## 记录原则

### DO ✅
- **实时记录**: 事件发生后30秒内完成
- **使用emoji**: 让记录可快速扫描
- **包含上下文**: 为什么做，不只是做了什么
- **可搜索**: 使用关键词方便日后查找
- **项目关联**: 如果是项目相关，同时更新 `memory/projects/xxx.md`

### DON'T ❌
- 不要记录闲聊
- 不要记录重复信息
- 不要覆盖已有记录（append-only）
- 不要记录敏感信息（密码、密钥等）

## 批量记录场景

当一次会话包含多个重要事件时，使用批量记录：

```bash
# 记录多个相关事件
./record.sh "事件1描述" "分类1"
./record.sh "事件2描述" "分类2"
./record.sh "事件3描述" "分类3"
```

## 紧急记录 (Emergency Record)

当OpenClaw即将重置或崩溃时，快速保存核心状态：

```bash
# 一键保存当前项目状态
./record.sh "紧急备份: [项目名] 当前进度 [X%], 待续事项: [1,2,3]" "项目"
```

## 记忆文件管理

### 每日文件结构

```
memory/2026-02-15.md
├── 时间戳头部
├── ---
├── 🎯 决策记录
├── 📝 代码变更
├── 🚀 里程碑
├── ⚠️ 教训记录
└── 💡 用户备忘
```

### 项目文件更新

当记录涉及活跃项目时，同时更新：

```markdown
# memory/projects/项目名.md

## 当前状态
- 进度: [X%]
- 最后更新: [时间]

## 待续事项
- [ ] [事项1]
- [ ] [事项2]
```

## Git提交规则

重要记录后自动提交：

```bash
# 记录后提交
git add memory/
git commit -m "memory: [简述记录内容]"

# 里程碑后打标签
git tag -a "项目-vX.Y.Z" -m "[描述]"
```
