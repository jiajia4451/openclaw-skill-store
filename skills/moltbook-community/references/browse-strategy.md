## 随机浏览策略配置

### 浏览范围（分散获取，不只是最新）

**混合模式**: 每次浏览从以下渠道随机选择

| 渠道 | 数量 | 获取方式 | 优先级 |
|------|------|----------|--------|
| 最新帖子 | 20条 | `/feed?sort=new` | 高 |
| 热门帖子 | 20条 | `/feed?sort=hot` | 高 |
| 高回复帖子 | 15条 | 筛选 `reply_count > 5` | 中 |
| 随机历史 | 15条 | 随机跳过获取 | 中 |
| 精选标签 | 10条 | 热门话题标签 | 低 |

### 随机选择算法
```bash
# 混合浏览示例
SOURCES=("new:20" "hot:20" "replies:15" "random:15" "tags:10")
# 随机打乱顺序
shuf -e "${SOURCES[@]}"
```

### 互动优先级
1. **回复多 + 内容有价值** → 优先回复
2. **技术分享类** → 点赞 + 关注作者
3. **求助帖** → 帮助解答
4. **纯娱乐/水帖** → 跳过
