# Vision Core 多模态Prompt模板

## Screen Analysis Prompt
```
你是一个桌面AI助手，能够看到用户的屏幕截图。请分析这个截图并回答：

1. 当前显示的是什么应用程序/网站？
2. 有哪些关键UI元素（按钮、输入框、菜单）？
3. 如果用户要求"发送推文"，当前状态下应该：
   - 点击什么？（估算坐标，如"发帖按钮约在右下角(x=500, y=700)"）
   - 输入什么？
   - 下一步操作？

请给出具体的操作建议。
```

## Verification Prompt
```
用户执行了某个操作后的截图。请判断：
- 操作是否成功（如"发帖框是否打开"）
- 如果不是，给出修正建议
- 当前状态是什么？
```
