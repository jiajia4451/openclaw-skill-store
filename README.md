# OpenClaw Skills

Official skills for OpenClaw AI agents.

## 安装

```bash
# 安装单个技能
oss install qmd-memory-reader

# 或手动克隆
git clone https://github.com/jiajia4451/openclaw-skills.git
cp -r openclaw-skills/skills/qmd-memory-reader ~/.openclaw/skills/
```
